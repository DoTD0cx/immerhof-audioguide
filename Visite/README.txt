INSTALLATION

1. Décompressez le dossier.
2. Remplacez le contenu actuel du dossier Visite par ces fichiers.
3. Envoyez le tout sur GitHub.
4. Ouvrez le site en ligne.
5. Appuyez sur « Télécharger les audios ».
6. Attendez le message confirmant que les 7 audios sont disponibles.
7. Passez en mode avion pour tester.

Pour ajouter une station plus tard, ajoutez une seule ligne dans le tableau
« stations » situé au début de script.js.
